# Invictus Africa WordPress downloads

## Installation packages

- [Download Invictus Editorial theme](https://github.com/witzyjim/witzyjim/raw/refs/heads/invictus-wordpress-download/wordpress-downloads/invictus-editorial-1.0.0.zip)
- [Download Invictus Core plugin](https://github.com/witzyjim/witzyjim/raw/refs/heads/invictus-wordpress-download/wordpress-downloads/invictus-core-1.0.0.zip)
- [Complete source, documentation and preview bundle](https://github.com/witzyjim/witzyjim/raw/refs/heads/invictus-wordpress-download/wordpress-downloads/invictus-wordpress-review-bundle.zip)

One companion plugin supplies the required resource-library and integration features; no extra paid plugin or page builder is required.

Use a staging site first. In WordPress, install the **Core plugin ZIP** through Plugins → Add New → Upload Plugin and activate it. Install the **theme ZIP** through Appearance → Themes → Add New → Upload Theme and activate it. Upload the ZIP files directly; do not extract them first.

The complete review bundle is for your developer and must not be uploaded as a WordPress theme/plugin. Read [the installation and migration guide](INSTALLATION.md) before changing the live site. Existing Elementor layouts and plugin compatibility need staging review. The live site has not been modified. Newsletter and chatbot services need their own real configuration.
